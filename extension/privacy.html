青简网页剪藏：数据与隐私

仅在你触发剪藏、选区、图片或视频命令时，扩展提取对应内容，直接发送到你配置的青简站点。扩展设置和 API 令牌保存在本机浏览器，不使用集中中转、分析或广告服务。

为识别社交信息流中右键点击的具体条目，扩展会在受支持站点安装页面目标监听器。权限、图片来源访问以及模型来源访问依照浏览器提示授权。页面反馈与区域选择界面隔离在 Shadow DOM 中。

文章中的图片会尝试复制到青简附件库，失败的图片保留原链接。视频剪藏读取页面可提供的字幕与封面，不上传视频或音频。只有你启用视频摘要、为令牌授权并配置模型后，字幕文本才会发送至指定模型服务。扩展会接收所配置的模型凭据并直接请求该服务，这与上游工作方式一致。

“预览 / 整页 / 仅链接”入口使用标签页会话存储保存草稿，并在扩展本地保留最近一次草稿副本。可通过该入口的清除按钮删除副本。

扩展采用 EdgeEver 的开源剪藏实现，使用青简品牌。源码、来源版本和修改说明随项目提供。
