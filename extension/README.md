# 青简网页剪藏

基于 EdgeEver Web Clipper，固定对照版本为 [`8fc9851c0b6a8e764b74a835237b2920c3b5120f`](https://github.com/tianma-if/edgeever/tree/8fc9851c0b6a8e764b74a835237b2920c3b5120f/apps/extension)。保留提取器、区域选择器、右键菜单、图片归档、设置、诊断、多语言和浏览器差异处理；剪藏内容直接保存到扩展设置中指定的知识库或分组目录，无需打开青简预览。

扩展源码基于 `vendor/edgeever` 中的上游版本，许可证为 **AGPL-3.0**。`UPSTREAM.json` 记录原始导入版本和文件哈希；青简已直接修改认证、设置和对应测试，使用管理密码。修改说明见 [MODIFICATIONS.md](MODIFICATIONS.md)。青简构建不代表 EdgeEver 官方扩展。

## 构建与安装

扩展需要 **Node.js 22.18+、Bun 1.4.4**。青简服务仍按项目正常方式部署。请用 Bun 安装扩展依赖：它会应用上游的 GFM 表格补丁，npm 安装不会应用该补丁，构建会明确拒绝继续。

```bash
cd extension
bun install --frozen-lockfile
bun run build
```

Chrome / Edge：打开 `chrome://extensions` / `edge://extensions`，开启「开发者模式」，选择「加载已解压的扩展程序」，加载 `extension/dist`。更新后在扩展管理页点击重新加载，来源网页也建议刷新。

Firefox：

```bash
bun run build:firefox
bun run lint:firefox
```

在 `about:debugging#/runtime/this-firefox` 选择「临时载入附加组件」，打开 `extension/dist-firefox/manifest.json`。沿用上游的 Firefox Desktop 140+ / Android 142+ 目标；正常长期安装需要 Firefox 签名，开发临时加载不需要。

## 连接青简

1. 部署青简，准备好登录网页时使用的管理密码。
2. 打开扩展的「设置」，填写青简站点首页地址和同一个管理密码，点击「测试连接」。
3. 选择默认知识库，或知识库内的分组目录，然后保存设置。未指定或原目标失效时，使用列表中的默认知识库；没有知识库时先在青简创建。
4. 在目标网页点击扩展的「剪藏当前页面」，或使用右键菜单。提取后直接写入默认目标，页面中会显示结果反馈。

扩展直接使用管理密码进行 HTTP Basic 认证，没有额外的剪藏令牌或文档权限分级。管理密码可访问剪藏接口中的所有文档和附件。站点地址和密码保存在浏览器本地；服务端复用现有管理密码校验，不额外保存密码。

## 通用剪藏行为

| 功能 | 行为 |
|---|---|
| 当前页面 | 优先保存当前选区；没有选区时自动选择站点专用提取器或通用正文提取器。 |
| 正文提取 | Readability、文章 / main 回退、Markdown 转换；保留标题、列表、代码、GFM 表格和链接。 |
| 右键选区 | 只保存点击时选中的内容；选区变化时回退到当时冻结的文本，避免误存整页；支持框架内选区。 |
| 选择区域 | 悬停高亮、点击选定；左右方向键扩大 / 缩小，上下方向键切换相邻区域，Enter 保存，Escape 取消；也可重选。 |
| 右键图片 | 生成含图片附件、来源和时间的新文档；Google 图片搜索记录搜索来源和关键词。无法读取时按上游流程申请图片来源权限。 |
| 图片附件化 | 正文先保存，再尝试下载最多 30 张图：单图 20MB、总计 60MB，仍受青简上传上限约束。失败图片保留原链接，并提示部分复制失败。 |
| 编辑冲突 | 下载图片期间如果你手动编辑文档，扩展不会用回填结果覆盖你的修改。 |
| 设置与诊断 | 地址、管理密码、默认目标、连接测试、浏览器 / 系统 / 扩展版本、网站访问状态及诊断复制。 |
| 多语言与页面反馈 | 英文、简体中文、日文、波兰文；页面提示和区域界面使用 Shadow DOM。 |

专用接口在存储时把上游 `/api/v1/resources/.../blob` 引用转换为青简 `/files/...` 附件路径。图片因此参与现有附件去重、引用统计、清理保护和 Markdown / ZIP 导出。平台标签（例如 `web-clip`、平台名及适用的股票标签）作为剪藏元数据保留。

| 站点 | 专用提取内容 |
|---|---|

| 小红书 | 笔记标题、正文、作者、时间、地点及图片，不包含评论。 |
| 知乎 | 回答 / 专栏、作者、完整正文及图片；页面 API 与 DOM 回退，不包含评论。 |
| Reddit | 右键条目、标题链接、作者、社区、正文、外链和图库，JSON 优先，不包含评论。 |
| GitHub | 仓库 / 代码树卡片：About、首页、语言、许可证、主题；About 为空时取 README 首段。 |
| Hacker News | Ask / Show / 外链帖详情，作者、原始时间、积分、主帖正文与外链，不包含评论。 |
| V2EX | 主帖正文、链接及补充，不包含回复串。 |
| 小宇宙 | 节目、播客、主播及完整 Show Notes / 时间线；展开说明，不下载音频。 |

| 雪球 | 文章、作者、时间、图片及明确链接的股票标签；从选中的信息流条目解析详情。 |
| 微信公众号 | 文章正文、元数据、修复标题与图片、清理推广；图文消息读取声明的完整图库。 |
| 即刻 | H5 / Web 详情及信息流、展开全文、图库和纯图片动态；拒绝登录重定向。 |
| 少数派 | 文章、元数据、更新段落、图片及原发布时间。 |
| 掘金 | 文章、元数据、图片和完整对照表格。 |
| 豆瓣 | 图书 / 电影 / 音乐评论、指定短评及个人日记，匹配具体条目并处理图片 Referer。 |
| Facebook | 指定动态、作者、时间、正文、图片；展开正文，不包含评论和隐藏内容。 |
| Instagram | 帖子 / Reel 文案、混合轮播封面和分图说明；补齐可读取的轮播项。 |
| LinkedIn | 登录 / 访客正文、作者、职业标题、时间及图库；展开正文并解开安全跳转链接。 |
| Threads | `.com` / `.net` 动态、正文、短链、引用和完整附件集合。 |
| Bluesky | 指定动态、链接、引用、全尺寸图片、链接预览和替代说明。 |
| Medium | 专用文章正文、标题、作者及发布时间。 |
| Substack 文章 | 文章及自定义域名识别；付费墙内容拒绝自动提取，仍允许显式可见选区。 |
| Substack Note | 指定 Note、完整段落、作者、时间和附件。 |
| YouTube | Watch / Shorts / 短链接，当前播放器、章节、字幕和时间戳；优先人工字幕。 |
| Bilibili | 视频及指定分 P、播放器状态、字幕和时间戳；拒绝直播、番剧及无效页面。 |

## 视频剪藏

YouTube / Bilibili 直接保存页面可提供的字幕、时间戳、章节、封面和来源信息。没有字幕时保存可读取的元信息；不生成 AI 摘要，不请求模型服务，也不上传音视频。

## 检查与验收

```bash
cd extension
bun install --frozen-lockfile
bun run typecheck
bun run test                 # 提取器测试及青简密码认证回归
bun run build
bun run build:firefox
bun run lint:firefox
npm ci --prefix ../web
npm run build --prefix ../web
bunx playwright install chromium
bun run test:browser          # 需要 Go，自动启动临时青简和本地文章夹具
cd ..
go test ./...
go vet ./...
cd web
npm run lint
npm test
npm run build
```

Chromium 测试加载真实构建产物并请求真实青简服务；仅测试副本的 manifest 预先授予 localhost 权限，分发产物保持原正常授权流程。测试创建独立临时数据库并在结束后清理。上游夹具覆盖平台差异、图片失败、编辑冲突、SPA 导航、定位条目、选区冻结及权限错误。

## 上游固有限制

站点改版、账号登录状态、付费墙、内容访问限制和图片防盗链仍会影响提取；保持上游的提示和回退行为。此版本没有增加上游尚未提供的截图、完整网页 HTML / PDF 存档、音视频下载或自动语音转写。源码中保留上游原始文档与版权，产品使用青简名称和图标。
