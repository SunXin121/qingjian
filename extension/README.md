# 青简网页剪藏

完整接入 EdgeEver Web Clipper，固定对照版本为 [`8fc9851c0b6a8e764b74a835237b2920c3b5120f`](https://github.com/tianma-if/edgeever/tree/8fc9851c0b6a8e764b74a835237b2920c3b5120f/apps/extension)。保留该版本的全部提取器、区域选择器、右键菜单、图片归档、设置、诊断、多语言和浏览器差异处理；保存到青简原生文档及附件。另保留第一版青简的预览、整页和仅链接入口。

上游原始文件存放在 `vendor/edgeever`，许可证为 **AGPL-3.0**。244 个导入文件（包括上游依赖补丁）保持原样，并由 `UPSTREAM.json` 逐文件记录 SHA-256。青简适配、品牌和构建改动见 [MODIFICATIONS.md](MODIFICATIONS.md)。青简构建不代表 EdgeEver 官方扩展。

## 构建与安装

扩展需要 **Node.js 22.18+、Bun 1.4.4**。青简服务仍按项目正常方式部署。请用 Bun 安装扩展依赖：它会应用上游的 GFM 表格补丁，npm 安装不会应用该补丁，构建会明确拒绝继续。

```bash
cd extension
bun install --frozen-lockfile
bun run build
```

Chrome / Edge：打开 `chrome://extensions` / `edge://extensions`，开启「开发者模式」，选择「加载已解压的扩展程序」，加载 `extension/dist`。更新后在扩展管理页点击重新加载，来源网页也建议刷新。

Firefox：

```bash
bun run build:firefox
bun run lint:firefox
```

在 `about:debugging#/runtime/this-firefox` 选择「临时载入附加组件」，打开 `extension/dist-firefox/manifest.json`。沿用上游的 Firefox Desktop 140+ / Android 142+ 目标；正常长期安装需要 Firefox 签名，开发临时加载不需要。

## 连接青简

1. 部署本次版本的青简，登录后打开侧栏「网页剪藏」（`/clip`）。
2. 点击「生成剪藏令牌」，复制这次显示的令牌。令牌不会作为明文存入服务端；重新生成或撤销会立即使旧令牌和编辑会话失效。修改管理密码后令牌也失效。
3. 打开扩展的「设置」，填写青简站点首页地址和 API Token，点击「测试连接」。
4. 选择默认知识库，或知识库内的分组目录，然后保存设置。未指定或原目标失效时，使用列表中的默认知识库；没有知识库时先在青简创建。
5. 在目标网页点击扩展的「剪藏当前页面」，或使用右键菜单。提取后直接写入默认目标，页面中会显示结果反馈。

剪藏令牌只访问专用接口：读取保存目标、创建文档，以及管理经剪藏接口创建的文档和其图片。它不能作为管理会话访问现有管理 API，也不能修改、删除普通已有文档。模型权限单独选择。站点 URL 和令牌保存在浏览器本地，不经过集中中转。

## 通用剪藏行为

| 功能 | 行为 |
|---|---|
| 当前页面 | 优先保存当前选区；没有选区时自动选择站点专用提取器或通用正文提取器。 |
| 正文提取 | Readability、文章 / main 回退、Markdown 转换；保留标题、列表、代码、GFM 表格和链接。 |
| 右键选区 | 只保存点击时选中的内容；选区变化时回退到当时冻结的文本，避免误存整页；支持框架内选区。 |
| 选择区域 | 悬停高亮、点击选定；左右方向键扩大 / 缩小，上下方向键切换相邻区域，Enter 保存，Escape 取消；也可重选。 |
| 右键图片 | 生成含图片附件、来源和时间的新文档；Google 图片搜索记录搜索来源和关键词。无法读取时按上游流程申请图片来源权限。 |
| 图片附件化 | 正文先保存，再尝试下载最多 30 张图：单图 20MB、总计 60MB，仍受青简上传上限约束。失败图片保留原链接，并提示部分复制失败。 |
| 编辑冲突 | 下载图片期间如果你手动编辑文档，扩展不会用回填结果覆盖你的修改。 |
| 设置与诊断 | 地址、令牌、默认目标、连接测试、浏览器 / 系统 / 扩展版本、权限状态及诊断复制。 |
| 多语言与页面反馈 | 英文、简体中文、日文、波兰文；页面提示和区域界面使用 Shadow DOM。 |
| 预览、整页、仅链接 | 扩展底部「预览 / 整页 / 仅链接」进入青简原有草稿流程；支持编辑、选目录、刷新恢复及上次草稿副本。这一入口暂保留远程图片链接。 |

专用接口在存储时把上游 `/api/v1/resources/.../blob` 引用转换为青简 `/files/...` 附件路径。图片因此参与现有附件去重、引用统计、清理保护和 Markdown / ZIP 导出。平台标签（例如 `web-clip`、平台名及适用的股票标签）作为剪藏元数据保留。

## 视频摘要

在青简「网页剪藏 → 视频摘要模型」启用并填写服务协议、完整 API 基址、模型名、密钥和输出上限；生成带「允许视频摘要」权限的新令牌，并在扩展中更新。

- OpenAI 兼容默认基址：`https://api.openai.com/v1`。
- Anthropic 默认基址：`https://api.anthropic.com/v1`。
- Gemini 默认基址：`https://generativelanguage.googleapis.com/v1beta`。

按上游方式，扩展请求青简准备提示词，然后接收模型凭据并**直接请求指定模型服务**。首次使用可能在扩展设置中提示授权模型来源。只发送当前视频的可用字幕和元数据；不上传音频 / 视频，不自动排队转写。摘要失败仍保存来源和字幕，缺少字幕时保存页面可提供的元信息。

Chromium 测试加载真实构建产物并请求真实青简服务；仅测试副本的 manifest 预先授予 localhost 权限，分发产物保持原正常授权流程。测试创建独立临时数据库并在结束后清理。上游夹具覆盖平台差异、图片失败、编辑冲突、SPA 导航、定位条目、选区冻结及权限错误。

## 上游固有限制

站点改版、账号登录状态、付费墙、内容访问限制和图片防盗链仍会影响提取；保持上游的提示和回退行为。此版本没有增加上游尚未提供的截图、完整网页 HTML / PDF 存档、音视频下载或自动语音转写。源码中保留上游原始文档与版权，产品使用青简名称和图标。
