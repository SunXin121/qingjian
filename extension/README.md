# 青简网页剪藏

参考 [EdgeEver 的浏览器剪藏流程](https://github.com/tianma-if/edgeever/tree/main/apps/extension)，基于 Manifest V3、Mozilla Readability 和 Turndown 独立实现。支持 Chrome / Edge 120+。

## 安装

先部署包含 `/clip` 页面的青简版本，再构建扩展。构建需要 Node.js 20+，运行扩展测试需要 Node.js 22.18+。

```bash
cd extension
npm ci
npm run build
```

1. 打开 `chrome://extensions` 或 `edge://extensions`，开启「开发者模式」。
2. 选择「加载已解压的扩展程序」，选中本项目的 `extension/dist` 目录。
3. 将「青简网页剪藏」固定到工具栏。
4. 打开要保存的网页，点击扩展，填写青简首页地址，例如 `https://note.example.com` 或本地开发地址 `http://localhost:5173`。仅支持部署在域名根路径的青简。
5. 首次剪藏时允许扩展访问你填写的青简站点。切换站点时会重新申请对应站点的权限。

更新源码后重新构建，在扩展管理页点击「重新加载」；已经打开的来源网页建议刷新后再剪藏。

## 使用

- **正文**：自动提取主要文章内容，尽量去掉导航与广告；不适合文章的页面可以换成整页模式。
- **选中内容**：先在网页中选中文字，再点击扩展，保留选区中的链接、强调等格式。
- **整页**：转换当前已经加载的页面内容；不会自动滚动加载后续内容。
- **仅链接**：只保存页面标题、来源网址和剪藏时间。

点击「提取并打开青简」后，扩展会在新标签页中打开青简的剪藏页。未登录时先登录，草稿会留在这个标签页。你可以修改标题、切换预览 / Markdown 并编辑正文，选择知识库及父目录，然后点击「保存到知识库」。保存成功后打开新文档。

支持标题、段落、列表、引用、常见表格、代码块、图片链接以及相对链接转换。图片保留原站 HTTP / HTTPS 地址，不会下载到青简附件；原站启用防盗链、要求登录或删除图片时，图片可能无法显示。预览不加载远程图片，保存后可在文档中查看。

单次草稿最多 1MB。浏览器内部页面、扩展商店、PDF 阅读器、iframe 内的选区，以及图片 / 视频 / Canvas 的原始内容不在此版本支持范围内。知乎、小红书等复杂站点尚未添加专用适配；正文提取不佳时可以使用选区或整页模式。

## 草稿与恢复

扩展只在你点击时读取当前网页；持续访问权限只申请给你指定的青简站点。不保存青简管理密码或登录 Cookie，也不需要放开服务器 CORS。

剪藏草稿通过扩展后台交给青简标签页的 `sessionStorage`，不放进网址、查询参数或服务器日志。青简仍使用自己的登录会话和同源 API 保存文档，标题与正文通过现有新建文档事务一起写入。

- 青简页面中的修改会暂存在当前标签页，刷新或重新登录后可继续。
- 青简保存成功或点击「丢弃草稿」后，会清除该标签页中的草稿。
- 扩展会在本机保留**最近一次提取的草稿副本**，供网络失败、页面关闭等情况恢复。点击「重新打开上次草稿」可再次交接；这个副本不包含你后来在青简页面中的修改。
- 点击扩展中的「清除草稿副本」可删除副本。副本不会同步到浏览器云端。
- 青简地址填写错误、从 HTTP 跳转到 HTTPS、或跳到其他域名时，扩展会停止交接。请填写最终站点地址后重试。

## 开发与测试

```bash
cd extension
npm test
npm run build
cd ../web
npm run typecheck
npm test -- src/clipper.test.ts
```

`src/extract.js` 负责正文与选区转换，`src/background.js` 负责跨标签页交接和恢复，`web/src/clipper.ts` 是双方共用的草稿协议与校验，`web/src/pages/WebClipper.tsx` 是青简接收与保存页面。

此扩展没有复制 EdgeEver 源码、品牌或站点专用适配。依赖许可证随构建输出保留：Mozilla Readability 为 Apache-2.0，Turndown 与 turndown-plugin-gfm 为 MIT。
