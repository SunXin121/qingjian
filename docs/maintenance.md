# 维护约定与待办

## 检查入口

根目录执行 `make lint`、`make test` 和 `make build`。Go 命令只扫描 `./cmd/... ./internal/... ./web`，避免进入安装依赖中的示例 Go 包。Web 的 ESLint 不允许警告。扩展验证命令见 `extension/README.md`，它使用独立的 Bun 锁文件和上游补丁。

## CSS 迁移

`web/src/styles.css` 是级联顺序的唯一入口。保留 `legacy` 层，以便 Tailwind utilities 覆盖旧组件样式；编辑器、表格、绘图库的第三方覆盖继续保持无层级。

- `form-controls.css` 管理旧表单、分段控件和开关；`icons-and-indicators.css` 管理图标选择器、图标遮罩及状态指示。
- 修改旧组件时，以组件为单位迁移至 Tailwind，并同时删除该组件已无引用的旧选择器；不要先删除整个 legacy 层。
- 推荐按表单控件、图标选择器、页面骨架、弹层、响应式及暗色覆盖的顺序逐步迁移。每步检查正常、禁用、焦点、暗色和窄屏状态。
- 完成最后一个旧组件迁移后，删除对应空文件、入口 import 和 legacy 层声明。以功能命名新文件，不再以改版轮次命名。

## 后续独立变更

以下工作需要独立验收，不与安全修复一起大规模改写：

- 将 GridView 的键盘、选择区、剪贴板与填充逻辑，以及 Sidebar 的树操作逐步抽取；先保留现有交互行为测试。
- 将 api.ts 的领域类型、请求封装和格式化函数拆分，保留过渡导出以减少调用处迁移风险。
- 持续把数据库读取与 HTTP 响应分开；新事务优先使用公共事务助手，业务校验保持明确的状态码。
- 在服务端实现与前端一致的公式、关联、查找引用与汇总计算后，再支持限定视图中的计算字段 / 表达式筛选。目前拒绝这些筛选，不得以整表回退。隐藏依赖不会随分享发送，依赖它们的前端计算结果可能为空。
- Mermaid 去重需要转换库支持 Mermaid 12，并通过流程图、时序图、类图到 Excalidraw 的回归验证。当前转换库声明 Mermaid 11，不能仅以覆盖依赖来认定兼容。
